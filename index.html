How a template gets here

  1. 01

    Commission

    One line in — "a landing page for a coffee roaster" is enough. The studio fills every gap with documented assumptions and never asks questions mid-build.

  2. 02

    The gauntlet

    Generated imagery, real copy, responsive build — then two independent adversarial reviewers plus a uniqueness diff against every existing template. Fail here means rebuild, not publish.

  3. 03

    Published

    Live preview, machine manifest, agent prompt kit, honest license. Humans download; agents read the same catalog as data.

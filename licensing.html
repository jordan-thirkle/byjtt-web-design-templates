Licensing, in plain English

The short version first; the formal terms follow. Every template page states which license applies to it.

The ladder

Free Template License

  • Use in personal, non-commercial end products.
  • Commercial use requires the Commercial license (paid templates) — this keeps the ladder honest.
  • Attribution appreciated, never required.
  • Modification is allowed and expected: it's your site.

Commercial License paid templates

  • Everything in free, for business end products, up to 5,000 end products or sales.

Extended License paid templates

  • Up to 250,000 end products / sales, and required whenever end users pay to access the end product.

Definitions

  • An End Product is a final, completed work that adds significant value beyond the template itself — your finished website is an End Product.
  • An End Product is not a UI kit, theme, or template, and not a tool that extracts or re-exposes the template's assets.
  • Licenses are non-exclusive, worldwide, and lifetime for the purchased version.
  • Ownership of the template files stays with ByJTT.

Not allowed

  • Redistributing or reselling the template (even modified) as a template, theme, or UI kit.
  • Building extraction or bulk-download tools on the template files.
  • Using the templates to build a competing template marketplace or automated template generator.
  • Open-sourcing or re-licensing the template code without written consent.

About payments

This marketplace is a static site and never processes payments. Paid templates link to an external checkout (e.g., Stripe Payment Link or Gumroad) operated by ByJTT. Digital templates are non-refundable once downloaded, unless the license is materially broken.
